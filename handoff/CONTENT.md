## 3. 一课怎么写

每个 `LessonStep` 只讲**一个点**。

```ts
{
  title: "山脊和山谷：只看 V 尖朝哪边",
  body: "山脊是向低处伸出的高地，像脊背；山谷是向高处凹进去的低地，像沟。\n同样高度的等高线遇到山脊，被推向低处；遇到山谷，被推向高处。",
  bullets: [
    "山脊：中间高、两边低，等高线凸向低处",
    "山谷：中间低、两边高，等高线凸向高处",
    "河流发育在山谷，水从高处流向低处",
  ],
  tip: "在「山脊」「山谷」之间来回切，只盯 V 尖指的方向，别记反。",
  scene: { type: "contourLab", props: { scene: "ridge" } },
}
```

写作要求：

- **先直观，后术语**：先说“像脊背 / 像沟”，再给“凸向低处 / 高处”。
- 正文 2–4 行，每行一个意思；不要一段 200 字。
- `bullets` 是考点，不是正文重复；每条可独立成题。
- `tip` 写“怎么记 / 怎么判断 / 最容易错在哪”，不要写空话。
- 口诀只在确实好记时用；不要每课硬凑。
- 不使用“众所周知”“显而易见”等词。

## 4. 图示与视觉

- 文字与背景对比要够；浅色字不要放在浅色底上。
- 图示里的关键方向（高处/低处、上游/下游）要有**箭头 + 文字**，不能只靠颜色。
- 等高线：山脊 V 尖指向低处，山谷 V 尖指向高处；同一张图里等高距要标注。
- 3D 场景必须能拖动；如果 3D 容易让人迷向，优先做“立体 + 俯视并排”的对照。
- 颜色沿用 `styles.css` 的 CSS 变量；新学科不要另起一套品牌色。
- 移动端 360px 宽：图表不能横向溢出，按钮不能挤成一行。

参考实现：`src/globe/ContourLab.tsx`（等高线实验室），是“直观优先”的样板。

## 5. 题目规范

### 基本

- 一题只考一个点；题干不绕弯。
- 干扰项要“像真的错”，不能凑数；选项互不重复。
- 解析三段：**正确答案 → 为什么 → 易错点**。
- 每题标注 `chapterId`、`pointId`、`difficulty`。
- 程序生成题必须保证：答案唯一、答案在选项内、最近 N 题不重复。

### 来源

```ts
source: {
  type: "textbook" | "exam" | "school" | "original";
  name?: string;
  year?: number;
  verified: boolean;
}
```

- 真题导入必须标来源和 `verified`。
- 没核对答案的默认 `false`，不进正式练习。
- 教材原文不整段复制；用自编表述。
- 历史事实至少两个来源核对；敏感表述保守。

### 题库位置

拆分后：

- 公开题：`apps/<subject>/src/quiz/`
- 私有题（学校试卷、孩子错题）：`content-private/questions/<subject>.json`，**不进公开仓库**
- 构建时合并；公开仓库不包含私有文件

## 6. 隐私与版权

- 不采集用户数据，不埋点。
- 学习记录只存浏览器 `localStorage`。
- 公开仓库不出现：
  - 孩子姓名、学校、班级
  - “西安城六区”等地区个人信息
  - 学校试卷扫描图、答案页照片
  - 教师姓名、内部资料
- `content-private/` 已加入 `.gitignore`，不要用 `git add -f` 绕过。
- 教材内容只引用必要概念，不复制大段原文。
- 图片、地图数据注明来源（见 README）。

## 8. 新学科内容结构（建议）

```text
apps/history/
├── src/
│   ├── manifest.ts        # 教材、章节、考试日期、版本
│   ├── lessons.ts         # 课程
│   ├── quiz/              # 题型生成器
│   └── scenes/            # 时间轴、地图、人物关系图等
└── ...
```

历史建议的 scene：

- `timeline`：按时间轴排事件
- `map`：疆域 / 路线 / 战役
- `relation`：人物 / 事件关系
- `sourceCard`：材料题（原文 + 问题）

生物建议的 scene：

- `cell`：细胞结构
- `microscope`：显微镜与装片
- `cycle`：光合 / 呼吸 / 水循环
- `ecosystem`：食物链 / 食物网

先做 1–2 个 scene 跑通，再批量写课。
