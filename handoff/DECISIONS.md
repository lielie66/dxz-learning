## D-001 · 单仓库多学科（monorepo）

- 日期：2026-11-08
- 状态：**Phase 1 完成（2026-11-23）；Phase 2a 外壳完成；Phase 2b 待做**
- 背景：地理、历史、生物要共用外壳、练习引擎、错题本；分三个仓库会复制三份核心代码，用户还要记三个地址。
- 决定：同一仓库，目标结构 `apps/geo|history|biology` + `packages/core` + `packages/content`。
- 后果：
  - Phase 1 已完成：`apps/geo` + 根 workspaces + `docs/geo/`
  - Phase 2 待做：外壳 / 页签 / 练习卡抽到 `packages/core`
  - 并行开发必须遵守 `AGENTS.md` 的“一个学科一个 owner”

## D-002 · 每个学科产出一个单文件 HTML

- 日期：2026-11-08
- 状态：已定
- 背景：目标用户是家长和孩子，离线双击可用是核心体验；不能要求装 Node 或起服务器。
- 决定：每个 app 继续用 `vite-plugin-singlefile`，产物是 `docs/<subject>/index.html`。
- 后果：
  - 共享 core 会被打进每个学科的文件（可接受）
  - 不做运行时按需加载 / 路由拆包
  - 单文件体积要持续观察

---

## D-003 · 无后端、无账号、localStorage

- 日期：2026-11-08
- 状态：已定
- 背景：不想维护服务器，也不想收集孩子数据。
- 决定：纯静态；学习记录存 `localStorage`；以后加导出/导入 JSON。
- 后果：
  - 换设备 / 清缓存会丢记录，需要导出功能
  - 不能做跨设备同步（除非以后加可选后端）

---

## D-004 · 发布渠道：GitHub + Gitee + EdgeOne 自定义域名

- 日期：2026-11-09
- 状态：已定
- 背景：GitHub 是主力背书，但国内访问不稳；Gitee 做镜像；EdgeOne 提供国内可打开的永久地址。
- 决定：
  - 代码主仓：GitHub `lielie66/dxz-learning`
  - 国内镜像：Gitee `acef09/dxz-learning`
  - 主站：`https://dxz.flowzen.cn/`（EdgeOne Pages，全球可用区不含中国大陆）
  - 离线包：GitHub Release / Gitee raw
- 后果：
  - 每次发布要同步三处
  - Gitee 开了 2FA，HTTPS 推送要 token 或 SSH
  - EdgeOne 目前是控制台手动上传，不是 Git 自动部署

## D-008 · 等高线用“水平切面 + 立体/俯视并排”

- 日期：2026-11-09
- 状态：已定
- 背景：2D 等高线图和自由旋转 3D 都试过，孩子仍分不清山脊/山谷。
- 决定：第 11 课改用 `ContourLab`：左边可旋转立体地形，右边俯视等高线，拖动切面高度同步；5 个场景标签；山脊/山谷直接标 V 尖箭头。
- 后果：
  - `ValleyContour` / `Terrain3D` 不再被课程引用（暂留，拆分时清理）
  - 新学科的可视化优先做“对照 + 可操作”，不要只放静态图

## D-009 · Chrome Safe Browsing 红页按“误报”处理

- 日期：2026-11-17
- 状态：进行中
- 背景：另一台电脑 Chrome 打开主站出现红色“欺骗性网站”；DNS、证书、腾讯网址安全均正常。
- 决定：
  - 不在站点侧做“绕过警告”的改动
  - 向 Google 提交误报申诉
  - 用 Transparency Report 判断是单 URL 还是根域名被标
- 后果：
  - 复核期间用户可手动“访问这个不安全的网站”
  - 不关闭 Chrome 安全浏览
